# 导入导出与迁移

> LockPass 不做云端同步（与零网络原则冲突，见 [[安全架构]]），跨设备迁移与备份全部通过**显式的文件 / 二维码**完成。

## 导出

右上角「导出」按钮支持两种格式：

| 格式 | 说明 | 安全性 |
|------|------|:------:|
| `.vault` | 加密 JSON（盐值 + IV + 密文，含迭代次数），需主密码解密 | 推荐，定期备份 |
| `.csv` | 明文表格，含全部类型字段 | 妥善保管，勿长期留存在电脑 |

## 导入

右上角「导入」按钮支持三种来源：

| 来源 | 说明 |
|------|------|
| `.vault` | 加密文件；使用文件内自带迭代次数，需原主密码 |
| `.json` | 加密备份：自动快照（`backups/LockPass-backup-*.json`）与文件同步产物（`LockPass-vault.json`） |
| `.csv` | 明文文件；导入时按「标题 + 用户名」自动去重 |

## 跨设备迁移

- **二维码**：详情面板「分享为二维码」→ 另一台设备「二维码导入」扫码 / 上传 / 拖拽 / 拍照，自动解密导入
- **.vault 文件**：导出 → 复制到目标设备 → 导入

> [!NOTE]
> 在线版与桌面版数据相互独立，用以上方式即可互通。

## 自动备份

| 方式 | 说明 |
|------|------|
| 定期提醒 | 提醒导出 `.vault`，间隔可配置：关闭 / 每天 / 3 天 / 7 天 / 30 天 |
| 自动加密快照 | `backups/LockPass-backup-*.json`，保留最近 N 份（可配置） |

## 从其他密码管理器迁移

1. 从原密码管理器导出 CSV
2. LockPass → 导入 → 选择 CSV

支持的列名：`title`、`username`、`password`、`url`、`category`、`notes`，另有 6 种条目类型的扩展字段（映射见 `src/core/import-bridge.js`）。
