# 浏览器扩展

> 浏览器扩展（Manifest V3）在解锁 LockPass 后，为任意网站的登录表单提供**一键填充**。扩展代码位于仓库 `extension/` 目录，版本随主应用发布。

## 安装

| 方式 | 步骤摘要 | 适用 |
|------|----------|------|
| 应用内获取 | 设置 → 浏览器扩展 →「下载 zip」 | 最简单 |
| Chrome / Edge | 下载 `lockpass-extension-v<版本>.zip`（[Pages 站点](https://trexwb.github.io/lockPass/) 随版本发布）→ 解压 → `chrome://extensions` 开启开发者模式 → 加载已解压的扩展程序 | Chrome / Edge |
| Firefox | 下载 `lockpass-extension-v<版本>-firefox.xpi` → `about:debugging` → 此 Firefox → 临时加载附加组件 | Firefox 115+ |

> [!TIP]
> 使用本地 `file://` 版 LockPass（双击 dist/index.html）时，需在扩展详情页开启「允许访问文件网址」。

## 使用流程

1. 打开并解锁 LockPass（在线版 / 本地版 / 开发版均可）
2. 在登录页面点击扩展图标 → 弹出条目列表（可搜索）
3. 点击条目 → 用户名与密码自动填入表单

> [!NOTE]
> 填充后**不会自动提交**：扩展会高亮提交按钮，由你确认后手动提交。

## 安全模型

| 项 | 说明 |
|----|------|
| 主密码不出主应用 | 解密只在 LockPass 页面内存进行，扩展仅转发密文请求结果 |
| 明文不落盘 | 明文密码只在「请求 → 转发填充」的瞬时内存中出现，用后即清；扩展无 storage 权限 |
| 会话令牌 | 解锁时生成一次性令牌（sessionStorage），锁定 / 登出即失效 |
| 来源校验 | 页面仅响应本窗口携带有效令牌的 postMessage 请求 |
| 不自动提交 | 填充后不触发提交，避免误操作 |

## 已知限制

- 需 LockPass 页面保持打开且处于解锁态（实时代理，扩展侧不做密码缓存）
- 表单识别基于通用规则（密码框定位 + 常见用户名选择器），复杂 / 动态表单可能识别失败
- 仅支持单条目点击填充，无自动弹出建议
