# LockPass · 个人密码工作台

> 纯前端离线密码管理器 —— Vue 3 构建，无后端服务器，数据永不离开你的设备。

LockPass 提供四种使用形态，数据模型完全一致，可互相迁移：

| 形态 | 说明 |
|------|------|
| **在线版** | GitHub Pages + PWA，浏览器直接打开即用 |
| **浏览器版** | 双击 `dist/index.html`（file:// 协议）即用 |
| **桌面版** | Tauri v2，覆盖 Windows / macOS，支持自动更新 |
| **浏览器扩展** | 解锁后一键填充登录表单 |

## ✨ 核心亮点

- 🔐 **端到端本地加密** — AES-256-GCM + PBKDF2 密钥派生，基于浏览器原生 Web Crypto API
- 📴 **零网络原则** — 无后端、无遥测、无 CDN 依赖，断网完全可用
- 🗂 **6 种条目类型** — 网站 / 服务器 / 数据库 / AI / 应用 / 其他，按类型语义化字段
- 🏷 **标签与关联** — 带颜色图标的标签体系；同 IP / 域名 / 账号自动关联跳转
- 🔄 **多通道迁移** — 加密 .vault、二维码扫码、CSV 导入、自动加密快照
- 🖥 **桌面自动更新** — 基于 minisign 签名校验的 Tauri updater
- 🧩 **浏览器扩展** — 解锁后一键填充登录表单，明文不落盘
- ⌨️ **快捷键 + PWA** — ⌘/Ctrl+K 搜索等全套快捷键，可安装到主屏幕

## 🚀 三分钟上手

1. 选择形态：直接打开[在线版](https://trexwb.github.io/lockPass/)，或到 [Releases](https://github.com/trexwb/lockPass/releases) 下载桌面安装包
2. 创建密码库：设置主密码（**唯一解锁方式，遗忘无法恢复**）
3. 添加第一条密码；复制密码后剪贴板会自动清除

> 详细步骤见 [[快速上手]]。

## 🔒 安全底线

> [!WARNING]
> 主密码不存储在任何地方，**忘记后数据无法恢复**。请务必牢记或妥善保管。

- 所有数据加密后存储在本机（浏览器 IndexedDB / 桌面应用数据目录），主密码与会话密钥不落盘
- 可选联网能力（自动检查更新）可一键关闭；核心功能完全离线
- 代码开源，加密基于浏览器原生 Web Crypto API，可独立审计
