# 常见问题

> 按主题整理的常见问题速查。

## 账户与数据安全

### 忘记主密码怎么办？

**无法恢复。** 主密码不存储在任何地方，是唯一解锁方式，只能销毁保险箱重新开始。建议将主密码妥善保管（例如离线纸质保管于安全位置）。

### 数据存储在哪里？

浏览器版 / 在线版存储在浏览器 IndexedDB（Chrome 位于 `~/Library/Application Support/Google/Chrome/Default/IndexedDB/` 等）；桌面版存储于系统应用数据目录（详见仓库 docs/tauri.md）。数据均为加密存储，见 [[安全架构]]。

## 多端与迁移

### 可以多设备同步吗？

**手动同步。** 通过 `.vault` 文件或二维码迁移（见 [[导入导出与迁移]]）。自动云同步与零网络原则冲突，不在规划内。

### 可以在手机上使用吗？

可以。在线版针对移动端做了底部导航、全屏详情面板、扫码导入与安全区适配，也可安装为 PWA（添加到主屏幕）。

## 桌面版与浏览器扩展

### 桌面版自动更新失败 / 没有提示？

检查 设置 → 关于 → 应用更新 是否开启「自动检查更新」；Release 处于 Draft 状态时更新清单 404 属预期，发布（Publish）后才可拉取。详细机制见 [[桌面版与自动更新]]。

### 扩展点击后没有填充？

确认 LockPass 页面已打开且处于解锁态（扩展为实时代理，不做缓存）；`file://` 版需在扩展详情开启「允许访问文件网址」。更多见 [[浏览器扩展]]。

## 兼容性与导入

### 支持哪些浏览器？

Chrome 60+ / Firefox 60+ / Safari 12+ / Edge 79+。

### 二维码 / CSV 导入会重复吗？

CSV 与 `.vault` 导入会按「标题 + 用户名」自动去重，无需手动清理。
