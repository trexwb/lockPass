# 快速上手

> 从零开始使用 LockPass：选择形态 → 创建密码库 → 日常操作。所有形态的数据模型一致，可通过 [[导入导出与迁移]] 互通。

## 1. 获取应用

| 形态 | 获取方式 | 适合场景 |
|------|----------|----------|
| 在线版（PWA） | 直接打开 <https://trexwb.github.io/lockPass/>，可「添加到主屏幕」 | 免安装，日常快速使用 |
| 浏览器版 | `npm run vite:build` 后双击 `dist/index.html`（file:// 可用） | 完全离线、本地文件掌控 |
| 桌面版 | 到 [Releases](https://github.com/trexwb/lockPass/releases) 下载（Windows: NSIS/MSI；macOS: zip/dmg） | 长期主力使用，支持自动更新 |
| 浏览器扩展 | 见 [[浏览器扩展]] | 登录表单自动填充 |

> 绝大多数用户直接下载安装包即可，无需自行构建。

## 2. 创建密码保险箱

首次打开显示「创建密码保险箱」界面：

1. 输入主密码（8 位以上，建议包含大小写字母、数字、符号）
2. 再次确认输入
3. 点击「确认创建」

> [!WARNING]
> 主密码是唯一解锁方式，**忘记后无法恢复数据**。安全机制详见 [[安全架构]]。

## 3. 日常使用

**添加与管理条目**

- **添加密码**：左下角「添加密码」→ 选择条目类型（网站 / 服务器 / 数据库 / AI / 应用 / 其他）→ 填写字段（可用内置密码生成器）→ 保存
- **编辑 / 删除**：删除进入回收站，可恢复或彻底删除
- **修改历史**：字段级快照（最近 5 版），可回滚

**查找与复制**

- **查找**：顶部搜索框按标题 / 用户名 / URL / 标签全文搜索；或按 `Ctrl/Cmd + K` 聚焦搜索
- **复制**：列表或详情面板一键复制，剪贴板 10/30/60 秒自动清除（可配置）

## 4. 推荐的首次设置

| 设置项 | 建议值 | 位置 |
|--------|--------|------|
| 自动锁定 | 5 分钟 | 设置 → 安全 |
| 剪贴板自动清除 | 30 秒 | 设置 → 安全 |
| 自动备份提醒 | 开启 | 设置 → 备份 |

## 5. 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + K` | 聚焦搜索框 |
| `Ctrl/Cmd + N` | 新建密码条目 |
| `Ctrl/Cmd + L` | 锁定密码库 |
| `Ctrl/Cmd + ,` | 打开设置 |
| `Escape` | 关闭模态框 / 面板 |
