## 2. 发现与处置

### 2.1 R1（P1）`--text-secondary` 设计令牌未定义

- **位置**：`entries.css`（回收站卡片标题、类型徽章、entry-subtitle）、`editor.css` ×2，共 5 处引用
- **影响**：`var(--text-secondary)` 未定义 → 颜色静默回退为继承色（text-primary），回收站条目、副标题的视觉弱化层级失效，深浅主题均受影响
- **处置**：base.css 新增令牌（深色 `#b6c2cf`，介于 primary `#e6edf3` 与 muted `#8b949e`；浅色 `#444c56`），5 处引用即刻生效 ✅

### 2.2 R2（P2）右键快捷菜单触屏不可达

- **位置**：`AppShell.vue` contextmenu 链路、`entries.css` .ctx-menu/.ctx-item
- **影响**：iOS Safari 不派发 `contextmenu` 事件 → 手机浏览器版右键菜单完全不可达；Android 长按虽触发，但卡片文字会被系统选中/弹出放大镜；`.ctx-item` 高度约 31px，低于项目自身的 44px 触控规范
- **处置**：
  - JS：新增长按 500ms 呼出（touchstart 计时 / touchmove·touchend·touchcancel 取消，滚动即中止，合成事件对象复用 `onCardContextMenu` 的视口钳制逻辑）；onBeforeUnmount 清理计时器
  - CSS：`(hover:none) and (pointer:coarse)` 下 `.entry-card` 禁止文字选择、`.ctx-item` 加大至 ≥44px、菜单 180px 宽、补 `:active` 按压反馈 ✅

### 2.3 R3（P2）`.btn-dropdown-menu` 硬编码白色

- **位置**：`layout.css` 添加密码下拉按钮组
- **影响**：边框 `rgba(255,255,255,0.14)`、按钮底/边 `rgba(255,255,255,0.04/0.07)` 在浅色主题下几乎不可见——与上轮 P2-8（cmd-field）同类问题漏网
- **处置**：改 `var(--border)` / `var(--border-dim)` / 透明底，阴影统一 `var(--shadow-lg)` ✅

### 2.4 R4（P2）详情面板标签 chip 颜色注入未过白名单

- **位置**：`DetailPanel.vue` `tagStyle()`
- **影响**：`--chip-color` 直接注入 `def.color`，绕过了 P3-6 只修 `renderTagChip`/`getCategoryIcon` 的白名单链路（导入恶意 vault 的 CSS 注入面）
- **处置**：`safeTagColor` 导出至 `window.Utils`，`tagStyle()` 统一过白名单 ✅

### 2.5 R5–R9（P3，低成本改进，一并落地）

| 编号 | 内容 | 处置 |
|------|------|------|
| R5 | `.entry-date` 重复 `font-size`（0.78rem 被 0.86rem 覆盖）死代码 | 删除 ✅ |
| R6 | 汉堡按钮 / 底部导航「标签」按钮缺 `aria-expanded` | 已补 ✅ |
| R7 | `.ctx-item` 字号 13px 硬编码（规范要求 rem） | 改 `0.93rem` ✅ |
| R8 | `empty-active` 用 `watch` + `getElementById` 手动切 class（Vue 反模式，违背「UI 状态由响应式驱动」） | 改模板 `:class` 绑定 ✅ |
| R9 | `.btn-dropdown-toggle` 白色分隔线 | 位于 accent 背景之上，深浅主题均可见，判定非缺陷，保留并记录 |

- 浅色主题：检查「添加密码」下拉菜单边框/按钮可见性；回收站条目标题弱化层级
- 桌面端回归：右键菜单、卡片 hover 操作、`empty-active` 空态居中不受影响
