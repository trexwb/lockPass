做得好的 10 项保持

引擎密码学质量
拒绝采样消除模偏差 + Fisher-Yates 洗牌 + minEachSet 逐组预置 + maxRepeat 重试上限——密码工具可信度的核心，实现正确。
命中区体系
chip 44px、滑杆 thumb 22px（40px 命中）、mini-btn 伪元素外扩 4px、移动端统一加大到 48px。
状态覆盖完整
全字符集关闭 → 空态 + 引擎回退双保险；footer 主按钮随语境切换复制/填入；复制反馈 1.6s 自动复位。
i18n 零缺失
组件 22 键 + 引擎 5 键在 zh/en 全部命中（23 键定义）；强度标签复用 editor.strength 保持全站一致。
深浅主题全令牌化
颜色/圆角/动效/字体全走 var()；强度四色走设计令牌，主题切换不漂移。
动效克制且有意义
逐字浮现 stagger 22ms、hover 光环、复制成功绿描边；prefers-reduced-motion 全局守护覆盖。
隐私设计正确
会话历史仅内存、不落盘、去重、上限 5 条。
弱密码双反馈
熵 <40 时强度条与预览文字同时变红，视觉通道冗余。
方案 C 架构解耦
独立弹窗叠加在编辑器之上，pwGenFillNonce 事件驱动回填、零耦合。
滑杆渐变填充
JS 计算 linear-gradient 实时反映当前值，视觉自解释。

问题清单 P2 ×3 · P3 ×7

级别问题与位置影响 / 依据建议修法
P2-A键盘焦点不可见
base.css:168 全局 outline:none；generator.css 零 :focus/:focus-within 规则——chips（checkbox opacity:0 可聚焦）、折叠头（tabindex=0）、mini-btn、历史项、滑杆全部无焦点指示		WCAG 2.4.7 失败；纯键盘用户无法定位焦点为 5 类控件补 box-shadow: 0 0 0 2px var(--accent-dim) 焦点环（与 btn-icon 既有样式一致）
P2-B历史复制反馈错位
copyPw：点历史第 N 条复制，绿框+「已复制」却出现在预览区——预览显示的是另一个密码		反馈与动作对象不对应，误导性强历史项局部反馈（dot 变绿）；或点击历史先置为预览再复制
P2-C折叠头语义不完整
pwgen-adv-head 缺 aria-expanded 与 Space 键触发（仅 Enter）		WCAG 2.1.1 / 4.1.2；读屏不知展开状态加 :aria-expanded + @keydown.space.prevent
P3-D预览区 user-select:none 与点击复制互斥——无法手动选中部分密码（如取前 8 位做 PIN）产品权衡；1Password 允许选择可维持现状（有完整复制兜底）或长按进选择态
P3-E空态提示用 warning 黄——操作引导非警告，语义过重.pwgen-empty改 --text-muted
P3-F历史区无清空入口（投屏/演示场景想立刻清掉做不到）隐私场景标题行加「清空」文字按钮
P3-GModalBase aria-label="pwgen" 非人类可读读屏播报改 :aria-label="t('pwgen.title')"
P3-H强度条无 progressbar 语义读屏无法感知强度值role=progressbar + aria-valuenow
P3-Ipwgen 与编辑器弹窗同 z(200)，叠加靠 DOM 挂载顺序胜出——可用但脆弱ModalHost L46 / modal.css显式 +1 层或注释固化
P3-J✓/▾ 文本符号与全站 SVG 图标体系不一致一致性（轻度，非 emoji 违规）换 Icons.check / 旋转 chevron SVG
