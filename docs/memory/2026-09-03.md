# 2026-09-03

## v1.0.3 — 修复手机端 BaseSelect 下拉"点击后不显示"

**问题**：手机端所有 select 下拉（EntryEditor / Settings / Import / Export / Tags 内的 BaseSelect）点击后菜单不显示。

**根因**（证据链）：
- `BaseSelect.vue` 菜单 Teleport 到 `<body>`，fixed 定位，`z-index: var(--z-dropdown)` = 300。
- 移动端（≤480px 或 ≤500px 高）`#modal-overlay` 被提升为 `calc(--z-detail-fullscreen + 1)` = 301（`modal.css:20-23`，历史上为解决"modal 被移动端全屏详情面板(300)遮挡"所加）。
- 所有 BaseSelect 均在弹窗内 → 移动端遮罩(301) > 菜单(300)，菜单实际已打开但被遮罩完全盖住。桌面端遮罩 200 < 300 故正常。
- 同样 Teleport 到 body 的 `CtxMenu`（`.ctx-menu`，entries.css:911）同 z=300，移动端弹窗内右键菜单有同样隐患，随 token 一并修复。

**修复**：
- `src/styles/base.css:83`：`--z-dropdown: 300` → `305`（高于移动端遮罩 301，低于 confirm 400 / float-tip 350）。
- `src/styles/modal.css:15`：同步注释中的层级数值。
- 使用 `--z-dropdown` 的三处（base-select-menu / ctx-menu / btn-dropdown-menu）全部受益，无需逐个覆盖。

**验证**：`npm run version:set 1.0.3` + `version:check`（11 处一致）；`vite build` 通过（72 modules）。Tauri 打包因本机 shell 缺 cargo 未执行（环境问题，与改动无关）。

**待人工**：真机/移动端模拟器回归一遍弹窗内下拉与右键菜单；README 更新日志补充 v1.0.3。
