# 版本迭代日志

> 本目录专门存储 LockPass 每次升级迭代的发布日志。
> 命名规则：`RELEASE-v{主版本}.md`（当前主版本 v1.0 → RELEASE-v1.0.md）

|------|---------|------|
| [v1.0 日志](RELEASE-v1.0.md) | v1.0.0 – v1.0.5（v1.0.0 全新起点，版本号整体重置） | 📝 待发布 |

---

## 约定

- **按主版本一个文件**：`RELEASE-v{主版本}.md`，次版本迭代作为分节追加到文件顶部（最新在前）
- **GitHub Release 正文**：面向用户的发布说明可单独成文，命名 `RELEASE-v{x.y.z}-github.md`（如 v1.1.3）；它是主日志的派生副本，内容随发布版本快照，不代替主日志的逐条记录
- **发布前**：在对应主版本文件追加该次版本分节，版本号统一经 `npm run version:set x.y.z` 同步（package.json / tauri.conf.json / extension / AGENTS.md / docs/spec.md 等全部派生）
- **发布后**：分节状态标记 ✅ 已发布；已发布内容只增不改（历史日志不可篡改）
- 待发布内容先以 📝 待发布 状态记录，发布时更新状态与日期
- 纯文档修改不升版本号；CI 脚本类修复按需随版本或独立记录
