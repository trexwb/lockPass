
## v1.0.1：Tauri 本地文件存储 API（15:34 完成）

### 背景
用户指出 Tauri 桌面版无法使用浏览器 File System Access API 做本地文件同步，需要新增 Tauri API 实现本地文件存储。

### 改动
- **src-tauri/src/lib.rs**：新增 5 个 Rust 命令（invoke_handler 注册）：
  - file_store_write(relative_path, contents) — 写文件，自动建父目录
  - file_store_read(relative_path) — 读文件
  - file_store_exists(relative_path) — 存在判断
  - file_store_delete(relative_path) — 删文件（不存在静默）
  - file_store_data_dir() — 返回数据根目录
  - 数据根目录 = app_data_dir（macOS: ~/Library/Application Support/com.lockpass）
  - safe_join() 路径穿越防护：拒绝绝对路径/.. /空路径/\0
- **js/file-store.js**（新模块，index.html 中位于 database.js 之后）：
  - window.FileStore：Rust 命令薄封装
  - 文件版 DBUtils：与 IndexedDB 版完全同接口（openDB/dbGet/dbPut/dbDelete/dbGetAll/dbClear/deleteDatabase + STORE_META/STORE_VAULT），Tauri 环境自动替换 window.DBUtils，业务代码零改动
  - 存储结构：meta.json（按 key 索引）+ vault.json（按 id 索引）
  - Promise 队列串行化写操作，防并发写丢数据
  - 浏览器环境自动降级（不替换 DBUtils），不影响 Web 版
- **js/settings.js**：refreshFileSyncStatus / refreshDataInfo 增加 Tauri 分支——显示数据目录路径，隐藏「绑定目录」按钮
- **scripts/test-file-store.mjs**（新）：Node 模拟 Tauri 环境测试脚本，20 项断言全过（读写/覆盖/删除/清空/并发 10 写/删库重建/落盘验证）
- **SPEC.md**：4.1 拆为「浏览器版 IndexedDB / Tauri 桌面版文件存储」双结构，7 项目结构修正为模块化现状
- 版本 v1.0.0 → v1.0.1（AGENTS.md / SPEC.md / js/app.js 三处 + README 更新日志）
