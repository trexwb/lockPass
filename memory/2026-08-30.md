**代码兼容性核查结论（无需改写扩展 JS）**：
- background.js / content.js / popup.js / lockpass-bridge.js 全部为 promise 风格 `chrome.*`（await/.catch），无回调式 API，Firefox 115+ 对 `chrome.action/tabs/runtime/storage` promise 语义全支持；

**改动**：

2. **`.github/workflows/pages.yml`**：扩展打包步骤改为调用 `node scripts/build-extension.mjs`，同时产出 Chrome zip + Firefox xpi 并校验；注释更新。

## 移动端抽屉滑动关闭手势 → v1.1.8

**用户需求**：手机端密码详情面板是从右侧滑出的抽屉，应支持手指右滑关闭；侧边栏同理支持左滑关闭。

**设计参考**：trae-remote-official:web-app-development:uicraft skill 的 interaction-design.md（"Making Gestures Discoverable" 原则）与 motion-design.md（300-500ms drawer duration、transform-only 动画）。

**改动**：

1. **`src/composables/useSwipeClose.js`（新建）**：通用水平滑动关闭 composable。
   - `touchstart` 记录起点 → `touchmove` 判断水平/垂直主导（水平位移 > 垂直+6px 死区锁定为"拖拽"态）→ `touchend` 超阈值（80px）或快速滑动（<300ms 且 >40px）触发 `onClose`。
   - `dragOffset` ref 驱动面板跟随手指位移；`isDragging` 标记拖拽态。
   - `isEnabled` 回调：返回 false 时禁用手势（桌面端非抽屉模式不启用）。
   - 垂直滚动优先：未锁定为水平拖拽前不干预垂直滚动（`touch-action: pan-y`）。

2. **`src/components/entries/DetailPanel.vue`**：接入右滑关闭（panel 在右侧 → `direction: 'right'`）。
   - `isEnabled: () => matchMedia('(max-width: 1024px)').matches && !!entry.value`（仅移动端抽屉模式）。
   - `panelStyle` computed：拖拽时内联 `transform: translateX(${dragOffset}px); transition: none`。
   - 模板：`@touchstart.passive` / `@touchmove.passive` / `@touchend.passive` / `@touchcancel.passive` 绑定。
   - 新增 `.swipe-hint` 元素（左边缘细条 + 脉冲动画，暗示可滑动）。

3. **`src/components/layout/SidebarNav.vue`**：接入左滑关闭（panel 在左侧 → `direction: 'left'`）。
   - `isEnabled: () => matchMedia('(max-width: 1024px)').matches && vaultState.sidebarOpen`。
   - 同样 `sidebarStyle` computed + 模板 touch 事件绑定 + `.swipe-hint` 元素（右边缘）。

4. **CSS（entries.css / layout.css）**：
   - `#detail-panel` / `#sidebar` 加 `touch-action: pan-y`（允许垂直滚动、捕获水平手势）。
   - `.swiping` 类：拖拽时加深 `box-shadow` + `user-select: none`（防止拖拽中误选文本）。
   - `.swipe-hint`：3px × 36px 圆角细条，`--text-tertiary` 色，`swipe-hint-pulse` 脉冲动画 2.4s 循环；拖拽中隐藏。
   - 仅 `@media (max-width: 1024px)` 可见（桌面端不显示）。

**设计原则遵循**：
- "Duplicate the path"：面板已有关闭按钮 (X)，滑动只是快捷方式，不是唯一路径。
- "Making Gestures Discoverable"：`.swipe-hint` 脉冲细条作为视觉暗示。
- "Animate Transform only"：拖拽跟随仅操作 `transform`，松手回弹走 CSS `transition: transform`。
- `prefers-reduced-motion`：base.css 已全局将 `transition-duration` 降为 0.01ms；直接操作（拖拽跟随）不受影响。

**验证**：`npm run vite:build` 67 modules 0 error 0 warning（618.19 kB / gzip 172.66 kB）；`npm run version:check` 11 处一致（v1.1.8）。未执行任何 git 操作。

## 移动端删除确认 + 触控交互优化 → v1.1.9

**用户需求**：手机端的交互动作需要调整，比如删除密码应该有确认动作。

### 1. softDelete 确认弹窗

**问题**：`softDelete`（移入回收站）有 4 个调用入口全部直接执行无确认——卡片删除按钮、卡片长按菜单、详情页底部按钮、详情页右键菜单。移动端触控极易误触。

**改动**：
1. **`src/composables/useVault.js`** `softDelete(id)` 函数（856 行）：在 `entry.deletedAt` 赋值前插入 `await window.Utils.confirm({ title, message, confirmText, danger: true })`，用户取消则 return。4 个入口点全部统一走此函数，全覆盖。
2. **`src/i18n/zh.json` / `src/i18n/en.json`**：新增 `vault.confirm.softDelete.title` / `.msg` / `.ok` 三组 key（中英双语）。

### 2. 移动端触控交互优化

**改动**：

1. **触控目标尺寸（`src/styles/entries.css`）**：
   - 新增 `@media (max-width: 480px)` 媒体查询：卡片操作按钮（copy/delete/star/restore）从 28px → **44px**（Apple HIG 触控下限）；
   - `.entry-actions` gap 从 4px → 6px（间距匹配更大按钮）。

2. **长按视觉反馈（`src/styles/entries.css` + `src/components/AppShell.vue`）**：
   - CSS 新增 `.entry-card.long-pressing` 类：`scale(0.97)` + 强调色边框 + `box-shadow` 光环；
   - `.entry-card` 加 `touch-action: manipulation`（禁用双击缩放，保证长按不被中断）+ `-webkit-tap-highlight-color: transparent`；
   - JS `onCardTouchStart`：触摸开始时加 `long-pressing` class + 轻振动反馈（10ms）；长按触发时清除 class + 强振动（30ms）；`cancelLongPress` 清除 class。

3. **详情页底部按钮（`src/styles/layout.css`）**：
   - `@media (max-width: 480px)` 中 `.detail-footer .btn` 加 `min-height: 44px`。
