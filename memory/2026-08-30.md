## 扩展 Firefox 兼容层（docs/upgrade-design.md 第三章） → 版本号未变更

**任务来源**：docs/upgrade-design.md 第三章「Firefox 兼容层」（3.1 manifest 适配 / 3.2 代码兼容清单 / 3.3 验证）。

**代码兼容性核查结论（无需改写扩展 JS）**：
- background.js / content.js / popup.js / lockpass-bridge.js 全部为 promise 风格 `chrome.*`（await/.catch），无回调式 API，Firefox 115+ 对 `chrome.action/tabs/runtime/storage` promise 语义全支持；
- `chrome.tabs.sendMessage` 已显式传 frameId（Firefox 不指定 frameId 仅发顶层，显式传更一致）；`chrome.runtime.onMessage` return true 异步响应 Firefox 支持；
- 故「同一份扩展代码」不改动，仅派生 Firefox 变体 manifest。

**改动**：
1. **`scripts/build-extension.mjs`（新建）**：双版本打包脚本——
   - Chrome 版：拷贝 extension/ → `dist/extension/chrome/`，zip 为 `dist/lockpass-extension-v<版本>.zip`（保持既有发布链接不变）；
   - Firefox 版：拷贝 extension/ → `dist/extension/firefox/`，派生变体 manifest（注入 `browser_specific_settings.gecko`：id=`lockpass-extension@lockpass.local`、strict_min_version=115.0；background 由 `service_worker` 改为 Firefox 的 `scripts` 声明，规避 SW 事件驱动休眠导致 setInterval 15s 轮询停摆），web-ext 打包为 `dist/lockpass-extension-v<版本>-firefox.xpi`（web-ext 缺失时自动回退系统 zip）；
   - 内置 Firefox manifest 校验（gecko id / min_version / background.scripts / manifest_version=3）与产物存在性校验。
2. **`.github/workflows/pages.yml`**：扩展打包步骤改为调用 `node scripts/build-extension.mjs`，同时产出 Chrome zip + Firefox xpi 并校验；注释更新。
3. **`README.md`**：新增「方式三：Firefox 安装（Firefox 115+，MV3）」说明（about:debugging 临时加载 .xpi）。

**验证**：
- `node --check` 扩展 4 个 JS + 脚本全部通过；
- `node scripts/build-extension.mjs` 幂等通过：Chrome zip（47K）+ Firefox xpi（46K，web-ext 路径）生成，Firefox manifest 校验通过；
- 本机未安装 Firefox，about:debugging 手动加载与填充回归（单/多字段/iframe/shadow DOM）留待用户按 README 方式三执行。
