# 2026-08-21 LockPass 变更记录

## 版本升级：v1.0.2 → v1.0.3（PATCH）

### 变更背景

修复 Tauri 桌面版导出失败 bug：打包成 macOS 应用后点击导出报错 `导出失败：invalid args `options` for command `save`: command save missing required key options`。

根因：`js/tauri-bridge.js` 调用 `plugin:dialog|save` 时参数平铺传入（`{ defaultPath, filters }`），但 Tauri v2 的 `tauri-plugin-dialog` `save` 命令签名要求 `{ options: { defaultPath, filters } }`，缺少 `options` 键导致参数校验失败。

修复：将 `defaultPath` 与 `filters` 包进 `options` 对象。其余插件调用（fs write/read_text_file、clipboard-manager write/read_text）传参结构核验无误，未改动。

## 补充修复（仍归 v1.0.3）：Tauri 桌面版链接点击无效

### 背景

打包成 macOS 应用后，密码详情面板「网址链接」和备注 markdown 解析出的 `[xx](https://xxx)` 链接点击无反应。前端所有链接均渲染为 `<a href target="_blank" rel="noopener">`（js/entries.js:143、js/utils.js parseMarkdown/safeUrl），浏览器版正常，但 Tauri v2 webview 中 `target=_blank` 默认不调起系统浏览器，点击静默失败。

### 修复内容

| 文件 | 修改内容 |
|---|---|
| src-tauri/src/lib.rs | 新增 `open_url` 命令：协议白名单（仅 http:// / https:// / mailto:）防注入；按平台 `open` / `cmd /C start` / `xdg-open` 调起系统浏览器；已注册进 invoke_handler |
| js/tauri-bridge.js | 新增全局点击委托（仅 Tauri 环境）：`document.addEventListener('click')` 拦截 `a[target="_blank"]`，preventDefault 后 `invoke('open_url', { url })`，失败 console.error + Toast |

### 版本号处理

本次修复归入 v1.0.3，不升号。仅 README.md 更新日志 v1.0.3 条目补充说明；AGENTS.md / SPEC.md / js/app.js / package.json / tauri.conf.json / Cargo.toml 版本号保持 v1.0.3 / 1.0.3 未动。

## 补充改动（仍归 v1.0.3）：侧边栏 UI 优化

### 需求

1. 左侧「热门标签」改为可收缩折叠：标题可点击，右侧 chevron 指示器（展开朝下、折叠朝右旋转）；折叠状态 localStorage 持久化（键 `lockpass_tags_collapsed`，'1' 折叠 / '0' 展开，默认展开），页面初始化恢复。
2. 「退出」按钮始终固底：侧边栏内容移入 `.sidebar-scroll` 滚动容器（flex:1 + min-height:0 + overflow-y:auto），footer 保持 #sidebar 直接子元素（flex-shrink:0），中间内容区滚动时退出按钮固定底部。

### 修改文件清单

| 文件 | 修改内容 |
|---|---|
| js/template.js | `<aside id="sidebar">` 内新增 `<div class="sidebar-scroll">` 包裹 4 个 section（添加密码/个人/类型筛选/热门标签）；热门标签标题改为可点击（id=tags-toggle、onclick=toggleTagSection()）+ chevron SVG；滚动容器在 footer 前闭合 |
| css/main.css | `#sidebar` overflow-y:auto → overflow:hidden；新增 `.sidebar-scroll`（flex:1; min-height:0; overflow-y:auto）、`.sidebar-title-clickable`（flex 布局 + cursor）、`.tag-chevron`（旋转过渡）、`#nav-categories.collapsed { display:none }`；`.sidebar-footer` 增加 flex-shrink:0 |
| js/main.js | 新增 `applyTagSectionState()`（初始化读取 localStorage 恢复折叠状态 + chevron 角度）与 `window.toggleTagSection`（切换 collapsed class + 持久化）；init() 中调用恢复 |

### 设计要点

- renderSidebar（ui.js）每次重写 nav-categories 的 innerHTML，折叠状态基于容器 class（collapsed），重渲染后状态不丢失；localStorage 兜底持久化。
- 移动端抽屉模式（#sidebar position:fixed + height:100vh）同样生效：footer 固定底部，中间内容滚动。

### 版本号处理

本次改动归入 v1.0.3，不升号；AGENTS.md / SPEC.md / js/app.js / package.json / tauri.conf.json / Cargo.toml 版本号保持 v1.0.3 / 1.0.3 未动；README.md 更新日志 v1.0.3 条目追加两行说明。
