- 全局 `@media (prefers-reduced-motion: reduce)` 关闭动效（可访问性必备）

## 修复 AI 类型「服务名称」无法保存 → v1.0.34（不额外升版本）

**修复**：将 `TYPE_FIELD_KEYS.ai` 改为 `['username', 'url', 'password']`，与编辑器模板顺序（服务名称 → API 地址 → Token）和详情面板 `DetailPanel.vue` 的 AI 展示逻辑（第 459 行已显示 `entry.username`）对齐。
