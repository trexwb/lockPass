## v1.0.3 — 修复备份 JSON 导入报「不支持的文件格式」

**现象**：批量导入弹窗选择自动快照 / 同步生成的 JSON 备份（`backups/LockPass-backup-*.json`、`LockPass-vault.json`）时，右下角 Toast 报「不支持的文件格式」。

**根因**：加密备份有两套信封，导入侧只认其一——

| 文件 | format 标记 | 结构 |
|------|------------|------|
| `.vault` 手动导出 | `encrypted` | salt + iterations + iv + data |
| 自动快照 / 文件同步 | `LockPass-file-sync` | salt + iterations + iv + data（同构） |

- `ImportModal.previewVault()` 仅接受 `format === 'encrypted' && data.data` 或明文 `entries`；快照 JSON 两条都不命中 → 落入 else 报错
- 主窗口拖拽导入 `import-bridge.js processFile()` 同样的 `format === 'encrypted'` 判断，同样漏掉快照

**修复**：两处均改为按加密封套结构识别——文件同时含 `salt + iv + data` 即走主密码解密流程，不再依赖 format 标记；解密逻辑不变（PBKDF2 按文件自带 salt/iterations 派生）。预览展示时间回退读取 `updatedAt`（快照无 exportedAt）。

**改动文件**：
- `src/components/modals/ImportModal.vue` — previewVault 加密封套结构判断
- `src/core/import-bridge.js` — 拖拽导入同一兼容
- `docs/spec.md` §3.11 — 格式表补 `.json` 行 + 识别方式说明
- `README.md` — 导入小节补快照说明；更新日志新增 v1.0.3

**验证**：
- 谓词行为测试：vault 导出 / 快照 / 明文 entries / 垃圾 JSON / 旧版无 iterations 五种形态分类全部符合预期
- `npm run vite:build` 通过
- `npm run version:check` 全部 11 处一致

**版本**：v1.0.2 → v1.0.3（PATCH，Bug 修复），`npm run version:set 1.0.3`

**注意**：改动留在工作树未提交，由用户决定是否 commit。

## v1.0.4 — 回滚功能优化：「密码历史」升级「修改历史」

**需求**（用户 4 点）：① 除密码外任意修改都生成记录；② 点击回滚先确认防误操作；③ 回滚成功删除被执行记录防重复执行；④ 回滚不新增记录（回滚不是编辑）。

**数据模型变更**：
- 旧：`history[id] = [{ password, at }]`（仅存旧密码）
- 新：`history[id] = [{ at, snap, fields }]` —— snap 为修改前可回滚字段深拷贝（title/entryType/username/password/url/port/notes/tags/root/appId/privateKey），fields 为本次变更字段列表；旧版仅密码记录兼容（只恢复密码，展示「旧版记录 · 仅密码」）

**实现要点**（`src/composables/useVault.js`）：
- `recordEntryHistory(id, prev, next, at)` 替代 pushHistory：diffKeys 全字段比较（histEq 深比较数组/对象、nullish 归一），有差异才入史；与最新一条快照全等去重；上限仍 5
- `rollbackEntry(id, at)` 替代 rollbackPassword：先 `window.Utils.confirm` 确认弹窗（danger，提示覆盖字段与不留副本）→ 应用快照 → 删除被执行记录（空则删 key）→ 单次 saveVault 原子落盘；**不再回写当前状态为新记录**
- `snapDiffers(entry, snap)`：回滚按钮禁用态 + 同版本守卫（旧版记录只比密码）
- favorite/showPassword 状态位不入史
- 导出 API 更名并新增 snapDiffers / describeHistoryFields

**UI**（DetailPanel.vue）：区块改名「修改历史」，每行 = 时间 + 掩码密码 + 变更字段说明；entries.css 加 .history-changed。

**验证**：16 项行为模拟断言通过（首轮 2 个失败为测试脚本断言笔误，修正后全绿）；vite:build 通过；version:check 11 处一致。

**版本**：v1.0.3 → v1.0.4。⚠️ 按规范本变更属功能增强、MINOR 需用户决定；AI 仅自增 PATCH（1.0.4），如需 v1.1.0 一句话即可 version:set。
